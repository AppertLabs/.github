# AppertLabs/.github

Org-wide default community files for AppertLabs repositories.

Right now that is the default issue forms (bug report and feature request) in `.github/ISSUE_TEMPLATE/`. GitHub shows them in any AppertLabs repo that has no `.github/ISSUE_TEMPLATE/` folder of its own. Repos with their own templates (for example the apps) use those instead.

This repo must stay **public** so GitHub can use it for org defaults. It holds templates only: no code and no secrets.
